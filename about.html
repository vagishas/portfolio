How I built this site

This website was built entirely with AI

I'm a designer, not an engineer, and I had never coded a website before. I designed this site in Figma, then built every page by working with AI (Claude). Every line of code here was written that way, and I learned how it all works along the way.

  1. Design to code. I gave the AI my Figma design and it turned it into HTML and CSS, then I reviewed it against the design and asked for changes, the same way I'd work with an engineer.
  2. Iterating in real time. I refined the layout, pinned the sidebar, swapped labels for icons and edited copy by describing what I wanted and checking the result.
  3. Debugging. When images didn't show up, I learned how file paths and folders work and fixed them.
  4. Resume and content. I built an A4 resume that's readable by applicant tracking systems, plus this page.
  5. Shipping it. I put the code on GitHub and deployed it live on Vercel.

What I took away

I now understand how a website is structured, how HTML and CSS fit together, and how code goes from my computer to a live URL. More importantly, I learned how to work with AI as a real collaborator: giving clear direction, reviewing its output with a designer's eye, and pushing back when something isn't right.

AI lets designers go from idea to working product much faster. That's something I'm excited to bring to my next team, whether that's prototyping ideas quickly or working more closely with engineers.
